# SkillMarket AI

SkillMarket AI is a freelance marketplace that connects skilled students and freelancers with clients. It provides a platform where users can showcase their talents, find projects, and collaborate with potential clients.

## Purpose

The purpose of this project is to help students and freelancers showcase their skills, discover opportunities, and connect with clients through a simple and efficient online marketplace.

## Features

- User Registration and Login
- Browse Projects
- Find Freelancers
- Freelancer Profiles
- Project Applications
- Dashboard Management
- Live Customer Support (Tawk.to)

## Technologies Used

- React
- TypeScript
- Replit
- GitHub
